## フルーツの色(円+**かわいい顔つき**のCanvas描画。画像は使わない)

顔は「絶対に死なんハムスター」風(2026-06-11 朱音さん要望・参考画像あり)。
**小さい点目(ハイライトなし)＋手書き調のシンプルなω口**で統一し、表情は目・眉で出す。
線は細め・焦げ茶(#4a3a30)。共通要素:控えめなほっぺ。スイカのみ縦縞。顔は回転と一緒に回る。
タイトルは「スイカゲーム（パチモン）」。書体は手書き風 Hachi Maru Pop(見出し・数字)＋ Yomogi(本文)。
UIの絵文字は廃止しSVGアイコン(やりなおす=丸い矢印・右上アイコンのみ / ランキング=トロフィー)。
HUD並び:ベスト / スコア / つぎ / リセット(アイコン)。デコポンは出っぱり無しのプレーン。

本体色は彩度を底上げしてビビッドに(fruits.js 読み込み時に `tone()` で `s×1.3` 補正)。
目・口・縁取りは本体より濃い同系色だが、黒へは寄せない同系色にする
(fruits.js の `tone()` で色相を保ったまま彩度を上げ・明度を落として算出)。
縁の濃さは果物ごとに `FRUITS[].rimL`(明度倍率・既定0.82)で調整。明るすぎた
さくらんぼ・いちご・なし・メロン・スイカは `0.6` でしっかり濃いめにしている。
イラスト調(フラット＋上だけ光)。枝・ヘタは縁取り付きで太め。

## サウンド(2026-06-11 追加)

Web Audio API の合成音(音源ファイル無し)。BGM=のどかポップなループ、効果音=落とす「ぷいっ」・合体「ポンっ」。
最初の操作で再生開始(自動再生制限のため)。BGM ON/OFF ボタンあり。合成音なので簡易。

待機フルーツは**雲が抱える**(本家風)。雲にも点目＋ω口の顔をつける。

## フルーツの形(本家方式・2026-06-11 追加)

当たり判定は**完全な円**(転がり・接触が自然で、重なり/隙間が出ない)。
見た目だけ円の上に果物の特徴を描く。**円からはみ出してよいのは上部のヘタ・葉・冠だけ**
(接触しない場所)。横・下を尖らせると隙間が出るので、円のまま＋陰影で形を表現する。
本体に放射グラデ(左上=光沢・右下=影)を重ねてまんまる感を出す。

小さい3種の当たり判定半径: さくらんぼ14px / いちご21px / ぶどう30px。
回転は描画専用で、物理ボディ・重心・周囲の果物には影響しない。移動中は横の移動距離÷半径で
円周距離と回転量を一致させる。一部の果物だけは静止後も1周約5分の極低速で一定自転し続ける。
接触中は床・壁で弱く減速し、果物同士では相対的な横滑りだけを質量保存で弱める。摩擦係数0、
反発0、重力・質量は維持し、隙間へ急に滑り込まずぬめっと動く手触りにする。
